# Objetivos de calidad

## Metas de calidad

- **Correctitud de funcionalidad:** Lograr que el 100% de los algoritmos de búsqueda y de recorrido de grafos que se implementarán pasen las pruebas funcionales para los casos de prueba definidos.

- **Control de defectos:** Finalizar el sprint sin errores críticos o de alta prioridad pendientes que impidan el funcionamiento de los módulos.

- **Validación de la gamificación:** Verificar que el 100% de las nuevas tareas y retos que se agregarán cumplan sus criterios de aceptación y funcionen correctamente dentro del sistema.

# Herramientas para las pruebas o tests

## Herramientas de pruebas

Para realizar las actividades de aseguramiento de la calidad, se utilizarán herramientas que permitan ejecutar pruebas, registrar defectos y verificar el funcionamiento de las funcionalidades desarrolladas.

- **Vitest:** Se utilizará una herramienta de pruebas automatizadas compatible con la configuración del proyecto para verificar el funcionamiento de los algoritmos y la lógica implementada.

- **Supertest:** Se utilizará para verificar los endpoints de la API desarrollada con Express, comprobando las respuestas y los códigos de estado esperados.

- **GitHub Issues:** Se utilizará para registrar y dar seguimiento a los defectos identificados durante las pruebas, indicando su descripción, prioridad y estado de resolución.

- **GitHub Actions:** Se planea utilizar para ejecutar automáticamente las pruebas cuando se incorporen cambios al repositorio, facilitando la detección temprana de errores.

- **Playwright:** Debido a que la aplicación cuenta con interfaces web, se planea utilizar para automatizar pruebas de navegación, interacción con la biblioteca de algoritmos y funcionamiento de las tareas de gamificación.
